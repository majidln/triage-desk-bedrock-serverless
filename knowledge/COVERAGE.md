# Coverage check

Questions a customer could ask that **no evaluation ticket asks**, and the guide section that answers each. A guide holds several topics, so the check is whether a retrieved chunk contains the answer, not just which file it came from. Step 4's retrieval check should run these too: if retrieval only works for the 42 tickets, the Knowledge Base is tuned to them.
